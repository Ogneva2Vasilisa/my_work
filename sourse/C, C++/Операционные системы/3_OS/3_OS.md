## Цель

**Изучить принципы разработки многопоточных программ, изучить программный интерфейс операционных систем для организации многопоточности, получить навыки организации взаимодействия потоков в многопоточных программах.**

## Задачи:

1. Вычисления (подбор знаков для линейного уравнения)
2. Quick Sort
3. MergeSort
4. Задача философов
5. Шахматы (найти количество расстановок заданного количества коней)

---
## Решение

**Вычисления.**

Общее количество подстановок знаков можно определить один числом, а его бинарное представление использовать в виде маски для подстановки знаков. Вначале программы это число делится на N_threads интервалов, и они распределяются по потокам. **Семафором** регулируется доступ к переменной с ответом.

**QuickSort.**

Сначала инициализируются **мутекс, замок** и очередь задач (откуда и до куда надо сортировать) с начальным значением { 0, N_A - 1 }. Каждый поток по очереди забирает задачу из очереди и сортирует. В процессе сортировки добавляются новые задачи, пока сортируемый массив не станет длиной меньше 100. Когда очередь станет польностью пуста, то потоки завершают свою работу. После выполнения всех потоков отсортированные масствы сливаются в один.

**MergeSort.**

Аналогично QuickSort, только реализация на Windows.

**Философы.**

Процесс синхронизации регулируется **семафором** официанта (официант - управляющий процесс), его начальное значение 2 – столько философов могут обедать одновременно. Все философы запускаются со своей структурой, которая содержит семафор, время ожидания вилок и состояния. Официант подает вилки тем философам, которые давно не обедали и у которых свободны вилки, чтобы исключить голодания. Программа заканчивается согласно условию.

**Шахматы.**

Каждый поток забирает задачу из очереди и ищет для нее все решения на своей локальной доске. Очередь задач состоит из изначально пустых клеток, и доступ к ней регулируется с помощью **мутекса**. Далее поток ставит первую фигуру на пустую клетку из задачи и перебирает все клетки слева-направо, снизу-вверх относительно задачи. Перебор идет рекурсией, то есть ставится фигура, ищется место для новой фигуры, ставится фигура, пока все фигуры не будут расставлены. Когда очередь пустеет, программа завершается.
