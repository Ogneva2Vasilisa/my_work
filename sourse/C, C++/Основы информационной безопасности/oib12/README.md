### Задача:

1.    Изучить настройку атрибутов безопасности с помощью стандартных средств Windows.
2.    Создать утилиту для управления атрибутами безопасности файла.

---
## Решение

Для управления правами доступа была разработана специальная утилита, которая позволяет создавать, читать, изменять и удалять ACE. После этого была разработана утилита, выполняющая действия создания, чтения, записи и изменения атрибутов файла. Если файл архивный, то не удается выполнить ни одну из операций чтения, записи и создания файла. Если же файл только для чтения, то не удается записать что-то в файл.
