## Задача

**Создание функционального распознавателя языка программирования Си, выполняющего лексический и синтаксический анализ исходного кода программ.** 

Распознаватель должен корректно идентифицировать и обрабатывать различные языковые конструкции, включая типы данных, операторы, выражения, управляющие конструкции и структуры данных

---
## Решение

В данной грамматике ее основой является часть, приведенная ниже. Она содержит весь перечень валидных конструкций, которые требуется анализировать с помощью распознавателя.

![](img/Pasted%20image%2020260104163702.png)

Далее написание грамматики свелось к раскрытию приведённых выше конструкций, уточнению тонкостей их использования.

Перечень конструкций, не поддерживаемых в разработанном распознавателе:

1. Препроцессорные конструкции, например, «#define» и «#include» не поддерживаются
2. Тип wchar_t и константы вида L'A', также char8_t, char16_t и char32_t и константы вида u8'N', u'Ы', U'Ю' – не распознаются разработанной программой
3. Спецификаторы класса хранения (extern, auto, register) аналогично не распознаются
4. Разработанная грамматика таже не распознает тернарный оператор
5. Функции выделения динамической памяти так же не поддерживаются

Также стоит отметить, что такой синтаксически важный для языка C символ как “;” был имплементирован на разных уровнях правил (также по мере их появления). Тем не менее, это не влияет на корректность работы парсинга.
