## Задача

**Изучить возможности встроенного в ОС Windows планировщика задач. Реализовать программу для управления планировщиком задач в ОС Windows, использующую возможности Windows API.**

Требования:

- программа должна уметь выводить список активных задач и их статус

- создайте правило, уведомляющее пользователя о внесении изменений в механизмы безопасности Windows: в работу встроенного антивируса Windows Defender, изменении любых настроек брандмауэра

- создать правило, уведомляющее пользователя, когда брандмауэр Windows блокирует ping-запрос с определенного IP-адреса

---
