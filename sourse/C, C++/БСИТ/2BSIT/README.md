## Задача

**Написать программу, работающую в качестве сервиса (службы) Windows (версии 7-10). Программа должна осуществлять резервное копирование данных из указанной директории.**

Требования:

1. Программа не должна быть интерактивной, все настройки задаются с помощью конфигурационного файла.

2. Программа должна создавать архив с резервной копией данных из указанной директории.

3. Файлы, включаемые в резервную копию, задаются по маске (с использованием символов ```*```, ?) или непосредственно по именам.

4. Резервная копия должна создаваться в виде архива формата ZIP.

5. Для архивации нельзя использовать сторонних процессов (т.е. нельзя использоваться 7zip и прочие программы архивации).

6. При изменении существующих или появлении новых файлов в исходной директории (соответствующих заданной маске) архив с резервной копией автоматически дополняется существующие (или заменяются новыми данными).

7. Инсталляция, деинсталляция, запуск, останов из командной строки (реализация своего SCP).

8. Корректный останов и перезапуск службы по запросу от SCM (обработка команд, передаваемых через оснастку "Службы").

9. Имена файлов и директорий задаются в формате UNC.

---
## Решение


Сервис начинается с функции ```_tmain``` .

![](img/Pasted%20image%2020260104224905.png)

После этого реализуются функции install, start, stop и remove. Для установки сервиса необходимо в программе связаться с системным процессом System Control Manager (SCM) через API. Далее с помощью функции CreateService создается сервис. Для функции start необходимо связаться с SCM, открыть сервис с правами на его запуск и с помощью функции StartService запустить его. Для функции stop необходимо использовать функцию ControlService с аргументом SERVICE_CONTROL_STOP. А удаление сервиса производится с помощью функции DeleteService. Весь код сервиса можно увидеть в приложении А.

Теперь переходим к реализации функции ServiceMain. Эта функция запускается при работе сервиса. Для начала нужно установить библиотеку libzip, с для работы с архивом. Это можно сделать с помощью менеджера пакетов NuGet. Для отслеживания изменений в директории используется функция из winapi: ReadDirectoryChanges. Она позволяет автоматически и оптимально отслеживать любые изменения в директории, в том числе добавление и модификацию файлов. Далее затем с помощью libzip добавляются нужные (по маске) файлы в архив.
