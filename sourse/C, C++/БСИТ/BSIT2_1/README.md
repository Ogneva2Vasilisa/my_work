## Задача

**Изучить существующие настройки безопасности пользователей в ОС Windows и возможности управления пользователями с использованием Windows API.**

Реализовать программу для управления учетными записями и контролем доступа в ОС Windows, использующую возможности Windows API.

- Программа должна выводить списки зарегистрированных в системе пользователей и групп, их SID и привилегии;

- Программа должна позволять добавлять/изменять/удалять пользователей и группы в ОС, а также удалять и добавлять, включать и выключать им привилегии

---
## Решение

Первым делом были написана функции для вывода списков групп, пользователей, их SID и их прав.

| **Функция**        | **Действие**                            |
| ------------------ | --------------------------------------- |
| NetUserEnum        | Возвращает список пользователей         |
| NetLocalGroupEnum  | Возвращает список групп                 |
| LookupAccountName  | Возвращает sid по имени                 |
| GetPrivileges      | Возвращает привилегии по sid            |
| GetUserLocalGroups | Возвращает группы пользователя по имени |

Далее был написан интерфейс для ввода команд с помощью switch case и заголовочный файл. Все функции для команд будут в отдельном файле.
Заголовочный файл

| **Функция**             | **Действие**                       |
| ----------------------- | ---------------------------------- |
| NetLocalGroupAdd        | Создание группы                    |
| NetUserAdd              | Создание пользователей             |
| NetLocalGroupAddMembers | Добавления пользователя в группу   |
| NetLocalGroupDelMembers | Удаление пользователя из группы    |
| NetUserDel              | Удаление пользователя              |
| NetLocalGroupDel        | Удаление группы                    |
| LsaAddAccountRights     | Добавление привилегии пользователю |
| LsaRemoveAccountRights  | Удаление привилегии у пользователя |
| AdjustTokenPrivileges   | Изменяет конкретные привилегии     |
