
Чтобы проверить, что индексы работают, надо проверить наличие ***Parallel Index** Only Scan using idx_fact_log_action on* в выводе
```
EXPLAIN ANALYZE 
SELECT l.log_type, COUNT(*) AS blocked_count 
FROM fact_network_events f 
JOIN dim_log_type l ON f.log_type_id = l.log_type_id 
JOIN dim_action a ON f.action_id = a.action_id 
WHERE a.action = 'blocked' 
GROUP BY l.log_type;
```

Удалить все мои индексы, но не ключи
```
DO $$
DECLARE
    r RECORD;
BEGIN
    FOR r IN
        SELECT schemaname, indexname
        FROM pg_indexes
        WHERE schemaname = 'public'
          AND indexname NOT LIKE '%pkey%'
          AND indexname NOT LIKE '%key%'
    LOOP
        EXECUTE format('DROP INDEX IF EXISTS %I.%I;', r.schemaname, r.indexname);
    END LOOP;
END $$;

```
