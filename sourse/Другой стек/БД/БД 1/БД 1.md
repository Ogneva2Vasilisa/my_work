Создать таблицу для импорта
```
CREATE TABLE raw_logs (
    timestamp TIMESTAMP,
    source_ip VARCHAR(50),
    dest_ip VARCHAR(50),
    protocol VARCHAR(20),
    action VARCHAR(50),
    threat_label VARCHAR(50),
    log_type VARCHAR(50),
    bytes_transferred BIGINT,
    user_agent TEXT,
    request_path TEXT
);
```
