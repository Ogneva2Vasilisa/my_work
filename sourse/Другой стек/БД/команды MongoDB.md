Конечно, разберём **основные команды MongoDB**, с помощью которых ты сможешь посмотреть:

– какие базы есть  
– какие коллекции есть  
– что внутри коллекций  
– метаданные  
– статистику  
– структуру документов

Ниже — кратко и чётко, без воды, чтобы можно было использовать как шпаргалку.

---

# **1. Просмотр баз данных**

### Показать все БД:

```js
show dbs
```

### Текущая БД:

```js
db
```

### Переключиться на БД:

```js
use mydb
```

---

# **2. Просмотр коллекций**

### Какие коллекции есть:

```js
show collections
```

Альтернативно:

```js
db.getCollectionNames()
```

---

# **3. Просмотр документов**

### Показать все документы коллекции:

```js
db.my_collection.find()
```

### Красивый вывод:

```js
db.my_collection.find().pretty()
```

### Показать ограниченное количество:

```js
db.my_collection.find().limit(10)
```

### Показать один документ:

```js
db.my_collection.findOne()
```

---

# **4. Просмотр структуры и статистики**

### Статистика коллекции:

```js
db.my_collection.stats()
```

Выведет размер, количество документов, индексы, storageSize, avgObjSize и др.

### Статистика базы:

```js
db.stats()
```

### Пример документа (анализ схемы):

```js
db.my_collection.findOne()
```

Если коллекция не схематична, можно посмотреть типы полей:

```js
db.my_collection.aggregate([
  { $project: { fieldTypes: { $type: "$someField" } } },
  { $group: { _id: "$fieldTypes", count: { $sum: 1 } } }
])
```

---

# **5. Просмотр индексов**

### Список индексов:

```js
db.my_collection.getIndexes()
```

### Статистика индекса:

```js
db.my_collection.aggregate([{ $indexStats: {} }])
```

---

# **6. Метаданные о коллекциях**

### Информация о коллекции:

```js
db.my_collection.getFullCollectionName()
```

### Размер коллекции:

```js
db.my_collection.stats().size
```

### Количество документов:

```js
db.my_collection.countDocuments()
```

---

# **7. Метаданные о сервере**

### Информация о версии сервера:

```js
db.version()
```

### Общая информация о сервере:

```js
db.serverStatus()
```
