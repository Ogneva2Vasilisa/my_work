## Задача

1.    Проанализировать выбранную СУБД с точки зрения специфики задач, на которых она демонстрирует наибольшую производительность.
2.    Разработать и аргументировать схему данных.
3.    Заполнить базу данных из набора, использовав весь набор исходных данных.
4.    Реализовать аналитические запросы из лабораторной работы 1.
5.    Оптимизировать запросы (используя индексы и другие доступные средства СУБД).
6.    Определить производительность запросов над схемой. Построить графики выполнения.
7. Сравнить полученные графики и данные с результатами работы №1.

---
## Решение

В качестве данных был выбран датасет Cybersecurity Threat Detection Logs, включающий в себя сгенерированные данные сетевого трафика и событий безопасности. Всего 6 млн строк событий. Столбцы в датасете_: timestamp, source_ip, dest_ip, protocol, action, threat_label, log_type, bytes_transferred, user_agent, request_path.

Загрузка данных в MongoDB осуществлялась из csv файла следующей командой:

```
"C:\Program Files\MongoDB\Tools\100\bin\mongoimport.exe" --db cybersecurity_db --collection logs --type csv --headerline --numInsertionWorkers 8 --maintainInsertionOrder C:\data\cyber_logs.csv
```

Далее было составлено несколько запросов:

| **Запрос** | **Назначение**                                                                |
| ---------- | ----------------------------------------------------------------------------- |
| 1          | Суммарный трафик по дням. Считает количество переданных байт для каждого дня. |
| 2          | Считает количество всех событий за каждый день.                               |
| 3          | Топ-5 IP источников по суммарному объему переданных данных.                   |
| 4          | Количество заблокированных соединений по типу лога.                           |
| 5          | Количество событий по типу лога и действию (blocked/allowed).                 |
| 6          | Считает суммарный трафик для каждого протокола и категории угроз.             |
