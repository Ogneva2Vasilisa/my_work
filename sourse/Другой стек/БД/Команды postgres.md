
Войти в postgres
```cmd
psql -U postgres
```

Кодировка
```
psql \! chcp 1251
```



Включить замер времени для каждого запроса
```
\timing on
```

| Команда | Что делает                                    |
| ------- | --------------------------------------------- |
| `\q`    | выйти из psql                                 |
| `\?`    | список всех команд psql                       |
| `\h`    | помощь по SQL-командам, например: `\h SELECT` |
### Базовые команды навигации

| Команда          | Что делает                                                   |
| ---------------- | ------------------------------------------------------------ |
| `\l`             | показать **все базы данных**                                 |
| `\c имя_базы`    | **подключиться** к базе данных                               |
| `\dt`            | показать **все таблицы** в текущей базе                      |
| `\d имя_таблицы` | показать **структуру таблицы** (столбцы, типы, ключи)        |
| `\du`            | показать **всех пользователей**                              |
| `\dn`            | показать **все схемы**                                       |
| `\conninfo`      | показывает, к какой базе и пользователю ты сейчас подключена |

### Работа с таблицами
|Команда|Что делает|
|---|---|
|`\d+ имя_таблицы`|расширенная информация (размер, описание, связи)|
|`\dt+`|список всех таблиц **с размерами**|
|`\copy имя_таблицы TO 'путь' CSV HEADER`|выгрузить таблицу в CSV|
|`\timing on`|включает **замер времени** выполнения запросов (очень пригодится для лабораторной!)|

### Мониторинг и активность

| Команда                                                 | Что делает                                                                                     |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `SELECT * FROM pg_stat_activity;`                       | показывает все текущие подключения и запросы                                                   |
| `SELECT * FROM pg_indexes WHERE schemaname = 'public';` | список индексов                                                                                |
| `\di`                                                   | показать все индексы                                                                           |
| `\x`                                                    | включает “расширенный режим” вывода (таблицы в вертикальном виде — удобно при длинных строках) |
