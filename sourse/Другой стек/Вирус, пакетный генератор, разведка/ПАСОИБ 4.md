## Задача

**Разработать генератор пакетов.**

---
## Решение

Была создана программа, которая позволяет генерировать сетевые пакеты по протоколам TCP, UDP, ICMP. Был использован язык Python и библиотека scapy. В начале работы ищутся все интерфейсы в системе, их ip и mac адреса с помощью функции get_if_list. Интерфейс выбора интерфейсов представлен на рисунке

![](/img/Pasted%20image%2020260107201551.png)

После выбора пользователь может выбрать протокол из трех представленных: TCP, UDP, ICMP. Для ICMP доступны только Echo Request и Echo Reply.

![](/img/Pasted%20image%2020260107201606.png)

Как тест, было проведено тройное рукопожатие с помощью ручного указания флагов и полей.

![](/img/Pasted%20image%2020260107201622.png)
