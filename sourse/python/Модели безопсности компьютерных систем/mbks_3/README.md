## Задача

Изучение методов и подходов анализа безопасности **мобильных приложений в условиях наличия (WhiteBox) и отсутствия (BlackBox) их исходного кода**. Изучение средств статического и динамического анализа. Получение навыков проведения проверки безопасности приложений и составления отчетов по результатам проведенного анализа

---
## Решение

В качестве whitebox были найдены все флаги CTF [InjuredAndroid](https://github.com/B3nac/InjuredAndroid).

В качестве WhiteBox нужно проанализировать приложение ВКонтакте. Для его анализа использовался OWASP MASTG. И в качестве инструмента для анализа apk-файла был выбран jadx и FlowDroid.
