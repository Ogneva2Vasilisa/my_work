## Задача

**Исследование принципов разработки моделей безопасности, функционирующих на уровне ядра ОС Windows.**

---
## Решение

Для разработки драйвера было использовано WDK для Visual Studio. За основу выбран NullFilter, так как он изначально полностью рабочий и с него удобно начинать писать свой фильтр.

Для работы драйвера используется конфигурационный файл, обработка которого происходит динамически при каждом изменении файла. Драйвер принимает на вход название процесса, для которого будут применяться ограничения, и имена файлов и ограничения к ним.

Во время работы драйвер проверяет каким процессом был открыт файл, и если такой процесс драйвер знает, то проверяет название файла, после этого в зависимости от настроек происходит запрет либо разрешение действия.
