## Task misc (network+pwn)

Для задачи в этой категории было принято решение записать трафик, чтобы с помощью фильтрации пакетов в программе wireshark можно было сразу найти порт и далее подключиться к серверу. Для этого я написала простую программу, где можно переполнить буфер и скомпилировала с определенными флагами: 

```
gcc task.c -no-pie -Wl,-z,norelro -O0 -o task_my_right -fno-stack-protector
```

```-fno-stack-protector``` — отключает защиту компилятора от атак типа Stack Smashing.

```-O0``` — отключает оптимизацию кода для чистоты эксперимента.

```-no-pie``` — опция компоновщика, указывающая на то, что мы не хотим позиционно-независимый исполняемый файл, использующий рандомизацию адресного пространства

```-Wl,-z,norelro``` — указание компоновщику не помечать глобальную таблицу смещений (GOT, Global Offset Table) как Read-Only для предотвращения ее перезаписи в процессе присваивания (RELRO, Relocation Read-Only) значений адресам загрузки разделяемых библиотек.

```C
#include <stdio.h>
#include <string.h>

int main()
{
  char giveflag[4];
  char word[256];
  strcpy(giveflag, "No.");
  printf("What's your favorite word? ");
  scanf("%s", word);
  if ( !strcmp(giveflag, "Yesss!") )
    printf("Flag is: MyCTF{good_net}\n");
  else
    printf("Good, but i won't give you flag.\n");
}
```

Далее поднимаем локальный сервер командой 

```
socat TCP-LISTEN:9999,reuseaddr,fork EXEC:./task_my_right,pty,stderr
```

Установив соединение с сервером, был включен захват пакетов со всех доступных интерфейсов. В консоли клиента вывелось:

```

Вложены файлы захвата трафика и исполняемого файла без пароля.
```

Сначала можно попробовать найти информацию, на каких портах ведется связь. Например, с помощью фильтра ```tcp && frame contains "word"```

## Task reverse

В этой категории было выбрано создать задание, где нужно угадать пароль для получения флага. 

Такую программу можно решить вручную, но такой просчет проверок займет много времени, поэтому в такой ситуации участникам лучше всего будет воспользоваться программами SMT-Solver.

```
Название: «Easy flag»
Описание: Я сделал программу, которая знает MD5 хэш моего секретика. Только вот незадача: я забыл пароль к нему. Помоги мне его вспомнить!
```

Исходный бинарный файл реализует следующую логику:

1. Программа запрашивает у пользователя ввод строки.
2. Далее идет несколько проверок на сумму цифр в строке, количество знаков «_» и расчет хэша MD5, не имеющего отношения к флагу.
3. Затем она применяет XOR-шифрование к этой строке с использованием заранее заданного ключа.
4. Программа сравнивает полученный результат с заранее зашифрованным значением.
5. Если результат совпадает, программа выводит флаг; если нет — сообщение об ошибке.

Для решения будет использоваться плагин ponce в программе IDA64.
